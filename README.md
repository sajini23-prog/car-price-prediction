##### Description:
 ###### This project analyses the key factors influencing automobile prices using a structured dataset containing multiple vehicle attributes. The aim is to identify which features have the greatest impact on pricing and build a predictive model.
##### Tools & Technologies:
###### Python / Excel
###### Multiple Linear Regression
###### Data Visualisation
##### Key Tasks:
###### Cleaned and preprocessed the dataset, handling missing and inconsistent values
###### Converted categorical variables into numerical format for analysis
###### Performed exploratory data analysis and descriptive statistics
###### Built a multiple linear regression model to predict car prices
###### Evaluated model performance using metrics such as R² and Mean Squared Error
##### Key Insights:
###### Engine size and horsepower strongly influence vehicle price
###### Fuel efficiency shows a negative relationship with price
###### Vehicle weight and size are positively correlated with pricing
##### Outcome:
###### Developed a regression model that explains price variations and supports better decision-making in automobile pricing.
